Jenkins Declarative Pipeline Orchestration

Visual execution workflow triggered via GitHub SCM webhook push events.

Pipeline Architecture & GitHub Integration

When changes are pushed to GitHub repository branch main, GitHub fires a webhook payload to http://jenkins-server:8080/github-webhook/. Jenkins automatically retrieves the source code, validates environment, runs automated unit tests with JUnit reporting, executes Terraform syntax & validation checks, performs a dry-run plan, and deploys to the cloud.
